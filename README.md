# Student Marks Calculator

A beginner-friendly mini project that calculates a student's total marks, percentage, grade, and pass/fail status.

## Features

- Enter a student name.
- Enter marks for five subjects.
- Calculate total marks out of 500.
- Calculate percentage.
- Display a grade and pass/fail result.
- Responsive layout for mobile and desktop.
- Clear the form and start again.

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Enter the student's name and marks for all five subjects.
4. Click **Calculate Result**.

## Marking Rules

- Each subject is out of 100.
- A minimum of 35 marks is required to pass each subject.
- A student who fails any subject receives grade **F**.

| Percentage | Grade |
|---|---|
| 90–100% | A+ |
| 80–89.99% | A |
| 70–79.99% | B |
| 60–69.99% | C |
| 50–59.99% | D |
| Below 50%, with all subjects passed | E |
| Failed in any subject | F |
